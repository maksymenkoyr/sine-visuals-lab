fix-conflicts: in a terminal, or `! fix-conflicts` in a session (function in ~/.zshrc; also npm run fix-conflicts) — a cheap headless model resolves a stopped rebase/merge's conflicts (tools/fix-conflicts.sh); `fix-conflicts <PR number>` first finds or creates that PR's worktree under .claude/worktrees/, moves into it and rebases it onto `origin/<base>`, resolves the conflicts, continues the rebase and pushes with --force-with-lease, stopping before the push if a file needs judgment (terminal only)
aliases: npm run aliases — print this list (tools/aliases.txt)
