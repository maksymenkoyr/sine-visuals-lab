fix-conflicts: in a terminal, or `! fix-conflicts` in a session (function in ~/.zshrc; also npm run fix-conflicts) — plain code settles the conflicts where both sides only added lines, a cheap headless model with a minimal prompt the rest of a stopped rebase/merge (tools/fix-conflicts.sh); `fix-conflicts <PR number>` first finds or creates that PR's worktree under .claude/worktrees/, moves into it and rebases it onto `origin/<base>`, resolves the conflicts, continues the rebase and pushes with --force-with-lease, stopping before the push if a file needs judgment (terminal only; the steps live in tools/fix-conflicts-pr.sh, so a terminal opened before an update still runs the current ones)
aliases: npm run aliases — print this list (tools/aliases.txt)
