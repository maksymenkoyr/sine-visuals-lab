Six ways the sand could change colour

Every plate below shows the same sand on the same fake 124 BPM song. They run the scene's own sand rule on the CPU, so the sand moves as it does in the app, only sparser. The only difference between the plates is how each grain is coloured.

Palette
While you hold it, every plate shows today's colouring.

Setting

Thrown grains

While a grain is being thrown, it changes colour, and it changes back when it lands. Today it runs up the palette toward white. This setting picks how far the colour moves and where it goes. At 1, Toward white, it is today's plate.

SmallTwo settings on the grain shader's colour line, which already knows how hard each grain is thrown.

Look

Two sides of a line

On either side of a still line the plate moves the opposite way: one side goes up while the other goes down. Each grain takes the colour of its side. Lines become seams between two colours, and the cells between them form a checkerboard.

SmallThe shader already works out the plate's value under every grain; this only reads its sign.

Look

Figure colours

 

Each figure gets its own colour, and sand takes the colour of the figure it settles on. When the music moves to a new figure, the old colour leaves its lines and the new colour gathers on the new ones, so you can watch the sand travel.

MediumEach grain has to remember its colour: a second state texture next to its position.

Look

Embers

Every hop heats a grain and rest cools it. A loud passage leaves the sand glowing, and it fades over a few bars once the plate calms. Sand that has rested a long time goes dark, so the newest lines are the brightest.

MediumEach grain keeps a heat value in a second state texture.

Music moment

Dyed sand

Re-dyes on every drop (bar 13).

On each drop the sand is dyed in a pattern by where it lies. The next figures carry the dye along and stir it, like coloured sand in a bottle. Beat waves instead recolours the plate from the centre on every kick.

MediumA dye per grain in a second state texture, set off by the Drop signal the app already has.

Look

Glitter

Each grain is a flat shard facing its own way. A light circles the plate once a bar, and a grain flashes when it faces the light, so the glints run through the palette once a bar. Thrown grains tumble and twinkle.

SmallThe facing angle comes from the grain's hash, and the tumble from how hard it is thrown, so nothing new is stored.

Already in the scene

  • Powder colour (draft PR #361) draws the light grains, which the air heaps between the lines, in a second palette colour. Thrown grains here use that same second colour.
  • Treble glow and Flash brighten the sand on hats and on the beat. They sit on top of any of these and are left out here.
