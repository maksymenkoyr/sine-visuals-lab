# Shared session scripts

Scene-agnostic tools rescued from working sessions — beat-synced
screenshotters, a probe for the auto→manual sign-off, a real-music headless
run, contact sheets and reference-frame measurers — kept here because they
used to live only in a session's scratch folder. Each file's header says what
it's for and how to run it; they may need adjusting to the current code.
Anything that proves generally useful belongs in `tools/`, cleaned up.
