# Sky (`sky`) — materials

This scene isn't on `main`: its code and its record (`docs/scenes/sky.md`) live in PR #133 (open). What it was built with is kept here so nothing is lost either way.

- Artifact: [Open Sky Illusions](https://claude.ai/artifact/UKtFCzHP3BBd987YmSVuZB). Source saved as `sky/artifacts/open-sky-illusions.html`.
- Artifact: [Sky Scene: Realistic Gas Cloud with Optical Illusions](https://claude.ai/artifact/C84CxowAYRsqzzzQWbaQsA). Link only (not saved here).
- `sky/scripts/` — the session scripts used to screenshot, probe or measure the scene, rescued from working sessions; each header says what it's for and how to run it, and they may need adjusting to the current code.
